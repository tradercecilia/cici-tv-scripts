## 脚本清单

- `cici_euro_spread_monitor_v1.pine`：欧元利差监控指标 v1

## 使用教程

1. 打开 TradingView 图表，在底部打开 **Pine Editor**
2. 清空编辑器中原有的代码
3. 复制仓库内对应 `.pine` 文件的全部代码，粘贴到编辑器
4. 点击 **Add to Chart**，加载指标到图表
